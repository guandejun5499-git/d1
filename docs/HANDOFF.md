## 游戏设计要点

部件组合决定 Δv，Δv 决定航线和收益；81 种组合里只有 8 种能到木星。世界布局参考 *Mine a Planet*，抽件→组装→飞行→赚钱→升级的循环参考 *Steel Fighters*。

**核心循环**

1. Roll 抽件：四个槽位（头锥、燃料箱、发动机、尾翼）× 三个等级，带保底。
2. 玻璃组装舱：半透明舱内可见组装过程，金属碰撞时溅火花，屏幕显示性能指标。
3. 点火：按住蓄力，在绿区松开；蓄到彩虹区松开是超级发射。
4. 绕星飞行：按节奏点击过门（PERFECT / GREAT / OK），可点星尘碎片。
5. 着陆：火箭底部进绿区时点 CATCH；忘记点会坠毁。
6. 结算金币 → 升级 Roll，解锁更高等级部件。

**Δv 性能模型**

- TWR = 推力 ÷ 湿质量；TWR < 1 无法起飞。
- 理想 Δv = 1000 × isp × ln(湿质量 ÷ 干质量)。
- 实际 Δv = 理想 Δv − 300 ÷ TWR − 100 × 阻力 − 80 ÷ 稳定性。

| Δv 区间 | 航线 |
| --- | --- |
| < 270 | 进不了轨道 |
| 270–899 | 月球 floor((Δv − 150) ÷ 120) 圈，最多 5 圈 |
| ≥ 900 | 月球 1 圈 → 木星 1 + floor((Δv − 900) ÷ 200) 圈，最多 3 圈 |

**结算公式**

单圈收益 = 基础值 × 头锥倍率 × 星级倍率 × (1 + 0.5k) × 发射倍率 × 过门评级 × 碎片充能 × 狂热倍率。基础值：月球 10，木星 60（从 35 上调，避免金头锥月球流赚得比木星多）。发射倍率：超级 1.6、完美 1.25、良好 1.1。

**最佳构建**：气动头锥 + 超大燃料箱 + 等离子发动机 + 后掠尾翼（Aero Nose + Mega Tank + Plasma Engine + Swept Fins），Δv 1107，航线月球 1 圈 → 木星 2 圈，轨道收益约 286 金币。

## 阶段一四个爆点功能

四个功能已全部在 Web Demo 中实现，目的是验证「爆点」是否真的提升爽感。

| 功能 | 规则 | 关键参数 |
| --- | --- | --- |
| 超级发射 | 点火蓄力经过绿 → 金 → 彩虹三段，在彩虹区松开即超级发射；蓄过头会熄火，第三段自动松开 | 每段 2.3 秒；彩虹区为第二段的 82%–88%；金币 ×1.6；白屏冲击波，击倒 25 格内的玩家 |
| 轨道狂热 | 同一趟连续 2 次 PERFECT 触发，之后每个 PERFECT ×2，失误即结束 | 门加宽 0.05 秒、变大 1.6 倍；飞行加速 1.2 倍；视野 +16°；尾焰 ×1.8 |
| 连续接住 | 跨飞行累计完美接住连击，回收倍率逐级上升 | 倍率 = 1 + 0.25 × min(4, n − 1)，连击 5 时达 ×2；连击 ≥ 4 出现电弧 |
| 壮观坠毁 | 着陆时没点 CATCH，火箭倾倒爆炸，维修无人机重建 | 残骸回收 50%；结算延迟 5 秒 |

**超级发射的引导**：首次前显示 NEW 卡片；蓄力条下方标出三个步骤并高亮当前步；按钮文字依次显示 RELEASE IN GREEN / KEEP HOLDING… / WAIT FOR RAINBOW… / RELEASE NOW!，到彩虹区时按钮变彩虹色。

**狂热的表现**：触发时顿帧、三连闪白、光环和 260 个粒子、大字 FEVER；持续期间按 140 毫秒节拍脉动，背景和轨道线变彩虹色，镜头带轻微翻滚摇摆和速度线；结束时做磁带减速音效并淡出。HUD 先显示 FEVER n/2，触发后显示倍率和计数。

场上还有三个参观 NPC（Visitor_Leo / Mia / Sam），会欢呼、被冲击波击倒。

## 调参与问题修复记录

每条修改都来自你的试玩反馈，最新的在前。

| 反馈 | 原因 | 改动 |
| --- | --- | --- |
| PERFECT 太难 | 视觉与判定错位约 0.3 秒；目标圈大小和门不一致；月球镜头侧向看不清轨道；窗口太窄 | 火箭改为居中在路径上；目标圈按门的投影大小缩放并加虚线轮廓；所有星球改用沿轨道法线的追尾镜头；窗口放宽到 ±0.18 / 0.22 / 0.27 秒；补偿 0.04 秒输入延迟；三声倒计时提示音 |
| 第 4 次 PERFECT 打不到，狂热触发不了 | 最佳构建一趟门数不够 | 你选择「降低门槛」：3 次 → 2 次 |
| 超级发射没人知道怎么触发；狂热不够炫 | 缺少 UI 引导；表现强度不够 | 加三步引导与按钮文字；狂热加节拍、彩虹、镜头摇摆和大字 |
| 金头锥月球流赚得比木星多 | 木星基础值偏低 | 木星基础值 35 → 60 |
| 绕木星时镜头不对 | 固定镜头挡住火箭；光环穿过轨道 | 改用追尾镜头；光环内移到轨道以内 |
| 解锁第二星球太平淡 | 没有演出 | 加木星解锁演出、绕星小技巧和全局特效 |
| 完美着陆不好玩 | 交互和反馈太弱 | 重做为绿区 CATCH 判定加慢动作和特效 |
| 点火镜头不对 | 镜头在组装舱后面 | 重新摆放点火镜头 |

**可能还要调的**：PERFECT 窗口大小、狂热时的镜头摇摆强度、各处慢动作时长。这些都还没有你的试玩结论。

## 代码结构与修改流程

整个游戏在一个 HTML 文件里，改参数直接搜下面的常量名。

| 常量 / 函数 | 当前值 | 控制什么 |
| --- | --- | --- |
| `WIN_P` | [0.18, 0.22, 0.27] | 三种尾翼的 PERFECT 窗口（秒） |
| `GREAT_PAD` | 0.18 | PERFECT 外的 GREAT 宽度 |
| `GATE_OK` | 0.5 | 超过则不算过门 |
| `INPUT_LAG` | 0.04 | 输入延迟补偿 |
| `FEVER_NEED` | 2 | 触发狂热所需连续 PERFECT |
| `IGN_CYCLE` | 2.3 | 点火蓄力每段时长 |
| `SUPER_ZONE` | [0.82, 0.88] | 彩虹区在第二段的位置 |
| `streakMult` | 1 + 0.25 × min(4, n − 1) | 连续接住倍率 |
| `BEST_BUILD` | 头锥 1 / 燃料箱 2 / 发动机 2 / 尾翼 1 | 扳手按钮装上的构建 |

其他关键实现：飞行路径由 `buildPath` 预先算好（贝塞尔曲线 + 轨道段，结果可复现）；慢动作和顿帧靠 `timeScale`；粒子用 `makePool` 的三个池；角色由 `makeAvatar` 生成（脚 → 腰部支点 → 身体，支持布偶倾倒）。

**修改和发布流程**

1. 修改 `orbit-roll-3d.html`，改前先备份。
2. 用 `node --check` 检查语法，再用 TypeScript（allowJs + checkJs）扫描未定义名称和声明前使用。
3. 在浏览器里实际试玩。会话环境连不上 cdnjs，所以 3D 版没有做过自动化运行测试，只做了静态检查。
4. 更新 artifact，再用包装脚本生成 `web-build\index.html`（补完整 `<head>`、viewport、主题色 #0a0f2e 和图标），重新打 zip。
5. 写入本地后核对文件大小。曾有一次把旧版设计文档写回本地，就是靠核对大小发现的。

## 会话中的其他讨论

这些是本次会话前半段的通用建议，详细版本在 `docs\SESSION_NOTES.md`。

**Roblox 独立开发**

- 尽早上线小而可玩的循环，用真实数据迭代；第 1 天和第 7 天留存对推荐最关键。
- 前五分钟最重要：约 30 秒内给一次爽快的升级，始终有看得见的下一个目标。
- 图标、缩略图、标题决定点击率，是游戏的一部分。
- 技术基础：服务器权威、可靠存档（带会话锁的 DataStore）、大数处理、手机优先 UI。
- 变现设计进游戏（增益、便利、外观），免费体验要好玩；规划持续更新、活动和兑换码。

**Discord 服务器**：先开 8–12 个频道：欢迎/规则、公告、更新日志、闲聊、作品展示、兑换码、建议（带投票）、Bug 反馈（置顶模板）、求助；1–2 个语音频道；私密的管理和开发频道。配合身份组、Roblox 账号验证和 AutoMod。

**从零开始做 Roblox 游戏的准备**：账号开启两步验证，装好 Roblox Studio；学 Luau 和客户端-服务器模型；研究同类 3–5 款游戏并严格控制范围；提前规划系统、目录和版本控制；使用 Creator Store 资源前检查恶意脚本。

**热门游戏（2026 年 11 月快照）**

- 在线人数靠前（11 月 18 日）：Steal An Egg、Brookhaven RP、Adopt Me!、Throw Food For Animals、Murder Mystery 2、Hyper Realistic Ragdoll。
- 增长最快的新游戏（11 月初）：DONT SPLASH、Break and Steal an Egg、Cat Battles、Turbo Soccer、RoWorld、Sell Fries!、Backseat Rally、Fake an Egg、Kukirin Life、Bike Universe。
- 趋势：「+1」增量游戏成批上线且好评率很高；偷取与收集循环；布偶物理；一句话就能说清的卖点。
