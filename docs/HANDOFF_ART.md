### Roll 与购买
- **Roll 按钮免费、无冷却**；只在约 1.2 秒开箱动画期间不响应。
- 所有部件台同时 Roll，每座台开出一个对应部位的部件，**标价出售**；玩家走到台前按 E 或在结果面板点 BUY 购买。没买的下次 Roll 被替换。
- 概率：每台独立 基础 55% / 高级 35% / 精英 10%。
- 保底：每座台独立计数，连续 10 次没出精英即进入保底；每次 Roll 从保底台里随机挑 1～2 座必出精英。
- 价格（金币）：鼻锥 气动 40 / 黄金 150；燃料舱 大 50 / 巨型 180；发动机 涡轮 60 / 等离子 220；尾翼 后掠 30 / 栅格 100。**基础件不出售、背包不限量。**
- 首次 Roll（新手引导后）：燃料舱台必出大燃料舱并免费赠送。

### 背包与待组装
- 部件流向：免费 Roll → 部件台购买 → **背包** → 组装舱槽位（**待组装**）→ 组装 → 发射台。
- 背包：同一种部件叠成一格，**重复只加数量 ×N**；取消原「重复 +1★、绕行金币 +5%」星级加成（数量留给阶段二「锻造融合」）。
- 放进槽位：背包数量 −1；✕ 移出或被替换：退回背包 +1。
- 待组装可随时修改并保存；四槽放满且组合能飞才能点「组装」，缺件显示「还缺：××」。
- 台上的火箭不受待组装影响，可直接发射；组装出新火箭后才替换。

## 4. 美术方向（已确认）

- 风格：**「玩具太空港」**——厚实圆润的玩具造型、SmoothPlastic 为主；亮色只给可互动和有反馈的地方；深紫夜空衬托火箭和轨道光效。用户要求场景模型风格参考 Roblox《Mine a Planet》（用户提供了截图：淡紫灰带凸点纹理的地面、悬浮平台 + 放射状连桥、发光熔岩 / 冰晶星球、霓虹光柱、Roblox 模拟器风格 GUI）。
- 色板：机身白 #F4F6FB + 石墨 #2E3247；品牌橙 #FF7A1A = 可互动；警示黄 #FFC93C；稀有度 基础银 #B8C2D1 / 高级蓝 #2F8CFF / 精英金 #FFC53D；尾焰 橙 / 蓝 / 紫；支架 L1 灰 #9AA3B5 / L2 蓝 / L3 橙 / L4 金发光；家园色 自己 #3BD85C，邻居 #FF5E7A #FFB33D #A46BFF #2FD3C8 #FF8AD8。
- 材质：SmoothPlastic 机身；Studs 只用在地台顶面；Neon 只做灯 / 全息 / 尾焰 / 门光边；Glass 用于组装舱；Metal 只做点缀；ForceField 做木星护盾和全息。
- 光照：Future；ClockTime 0 + 星空；Bloom Intensity 0.7 / Size 28 / Threshold 1.6；ColorCorrection Saturation +0.12 / Contrast +0.08；每个家园 ≤ 8 盏 PointLight。
- 比例：R15 角色 5 studs；火箭 10.4（首航）～ 15.8（最优）studs。

### 火箭部件（D1，已确认）
- 统一机身 Ø4，接口环 Ø4.4 × 0.35（石墨）；轴心在底面中心，按 发动机 → 燃料舱 → 鼻锥 沿 Y 堆叠；尾翼 4 片 45° 分布挂在燃料舱底部 0–3 studs。
- 高度：发动机 3 / 3.4 / 3.4，燃料舱 4 / 6 / 8，鼻锥 3 / 4 / 3.4。
- 机身统一白 + 石墨，档次色只在环带、尖端、尾翼、发光件；燃料舱顶一圈是玩家家园色；黄金鼻锥整体镀金。

### C2 玻璃组装舱 · 机械科技版（已确认）
- 外框 16 × 16、底座 18 × 18、总高约 22.1、舱内净高 18.8。
- **只有舱门对面一面是石墨机械墙**（4 个**部件坞**放待组装部件、管线），其余三面整面玻璃，**前角不设立柱**；「待组装」信息屏在舱门上方门楣、朝舱外（11-24 用户调整）。
- 顶部龙门吊（横梁 + 小车 + 缆绳四指抓爪）、两台落地焊接机械臂、中央转台升降台（Ø7.6，两侧液压支柱）、朝发射台的滑动舱门（5.2 × 14）、舱外控制台。
- 状态灯：青 = 待组装，绿 = 可组装 / 完成，黄橙闪烁 = 组装中。
- 组装演出约 5.6 s：龙门吊吊发动机 → 机械臂装尾翼 → 吊燃料舱对接焊接 → 鼻锥落位 → 全接缝点焊、转台转一圈 → 舱门打开送上发射台。**Web Demo 仍是旧的 4.8 s「从舱顶落下」演出，待同步。**
