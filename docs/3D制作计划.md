## 三、技术与收尾

| # | 项目 | 说明 |
|---|---|---|
| T1 | 零件预算与性能 | 玩家家园 586 件；六家全量约 3500 件，加上火箭与特效会更多。建议邻居用简化版（LOD）、岩体与地台继续用实体运算合并、开启 StreamingEnabled，并在手机上测帧率 |
| T2 | 删除临时验收台 | `_PartsReview`（1332 件）验收完删除；ServerStorage 里收起的 Baseplate 可一并清理 |
| T3 | 建造脚本参数化 | ✅ 11-24 完成：`build(K, LITE)` + `TARGETS`，家园色 `B.homeColor(K)`，简化版用 `B.lite` 删细节件 |
| T4 | 已知渲染限制 | Glass 和 ForceField 背后的半透明物体不渲染（全息、屏幕文字）；挂在半透明玻璃前的 SurfaceGui 会被吃掉；夜间时段隐藏自定义天空盒；圆锥网格尖顶被截平，侧面 r(t) = R·(1 − 0.925 t)。做新资产时沿用现有绕开办法 |
| T5 | Web Demo 同步 | Web Demo 还停留在：中心距 110（Roblox 11-25 起为 122，家园 / 广场半径 55 / 60，家园坐标表已放大约 1.3 倍）、两面机械墙组装舱、橙色多层 Roll 按钮、旧部件台高度、v1 部件造型、4.8 s 组装演出；打包文件 `orbit-roll-web.zip` 未重新打包 |

## 五、建议执行顺序

> **11-24 进度**：P0 第 1–11 项已全部做完，等用户验收（验收台 `_P0Review`，模块和接口见 `HANDOFF_STUDIO.md` 第 14 节）。验收通过后从 P1（第 12 项起）继续。

1. **参数化建造脚本，铺满 5 家邻居**（T3 → 1），同时决定邻居用全量还是简化版。
2. **支架 L1–L4 + 开合两态 + 接住区光柱**（2–4）：直接决定 Loop 1 的「升级支架」反馈。
3. **尾焰、轨道门、星尘碎片、木星轨道**（5–8）：飞行必需。

5. **组装演出、Roll 揭晓、发射与接住特效**（12–16）。
6. **坠毁 + 维修无人机、木星解锁、访客、广场雕塑、流星**（17–21）。
