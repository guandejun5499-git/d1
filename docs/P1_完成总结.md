## 二、通用做法

- **全部是客户端表现**，每项演出一个 `ReplicatedStorage.OrbitShared` 模块：`prepare(...)` → `show:at(t)`（纯函数，编辑模式可逐帧截图）/ `runTo(t)` / `play()`。以后服务器只发「开始演出」和最终状态。
- **通用特效 `ShowFX`**：`sparks` 火花、`chunks` 弹跳火星、`flash` 闪光、`ring` 地面冲击环、`puff` 烟 / 尘、`confetti` 彩色纸屑、`shake` 一次性震动、`rumble` 持续轻震。生成物放在 `Workspace._ShowFX`（不存档）。
- **镜头震动**：统一的「震感」控制器（相机更新后叠加平滑噪声位移 + 转角，强度 = 震感²，离角色 90 格外不震）。
- **踩过的坑（已写进 HANDOFF）**
  - 逐个零件摆位后，嵌套模型的轴心会留在原地 → 全息环绕错误位置乱转；演出收尾必须把嵌套轴心放回。
  - StreamingEnabled：客户端可能还没收到零件，演出里要 `WaitForChild` 兜底；木星改为 Persistent 常驻。
  - 新版 R15 生成器的关节是物理约束，客户端改不动，需换成 Motor6D。

## 三、逐项说明

### 12 · 组装演出（约 8.4 s）
- 龙门吊真吊：横梁沿 X、小车沿 Z、缆绳伸缩；发动机 → 尾翼（两台机械臂装）→ 燃料舱 → 鼻锥依次落位；部件在坞里 0.3 倍，吊离墙后边走边放大。
- 全接缝点焊 + 焊花 → 焊接臂收起 → 转台转一圈 → 状态灯转绿 → 舱门滑开 → 运输带（先直行再斜向）送上发射台；回收支架放平迎接，到台心合拢夹紧。
- 每次落位：撞击火花、弹跳火星、橙闪、冲击环、镜头轻震。
- **按用户反馈改过**：删掉挡路的两根液压支柱；焊接臂挪到尾翼之间的空档；舱门加宽加高到 10 × 17.2；运输带改两段；全程碰撞扫描后不再穿模。
- **部件坞铭牌**：随放入部件变化——上为级别条、下为大字部件名，底色按稀有度（基础灰 / 高级蓝 / 精英金，与 Roll 台价格卡一致），空位写「空位 · 待放入」；第二版加大、提亮，隔玻璃 20 格可读。
- 去掉 Roll 台、发射台、组装舱底座的黄色虚线 / 警示块。

### 13 · Roll 揭晓（约 3.95 s）
- 按钮按下回弹 + 绿色冲击环 → 4 颗青色能量光球沿弧线飞向 4 座台 → 台子进入「开箱中」→ 按稀有度从低到高依次揭晓：部件和价格卡弹出、同色爆闪 + 冲击环 + 光柱（基础 12 白 / 高级 24 蓝 / 精英 48 金）。
- 精英额外：金色火花雨、大范围闪光、镜头轻震，之后留下常驻金色光柱。
- 买下：部件缩成稀有度色光球，0.7 s 弧线飞进玩家（实时跟随），落身上爆火花 + 冲击环，台子转「已售出」。

### 14 · 点火与发射
- **蓄力**：台下暖光随强度闪动、尾焰逐渐变大、点火即冒烟；超载段火箭抖动冒白汽；彩虹区尾焰和暖光变彩虹；镜头随强度轻震。
- **发射**：
  - 普通 / 完美：强光 + 金白双层冲击环 + 贴地翻滚的烟雾 + 火花 + 震动。
  - 超级：白色大闪光 + 白 / 粉 / 蓝三层冲击环 + 6 色彩虹火花 + 彩虹尾焰 + 更强震动。
  - 超载熄火：剧烈抖动、黑烟、尾焰断续熄灭后重新点着，弱发射。
- 离台瞬间回收支架张开；离台时保持原尺寸，约 20 高后 1.9 s 内平滑放大到飞行比例 1.5。
- **按用户反馈改过**：全息小光圈乱转（轴心问题）；发光太久才冒烟；一离台就变大；点火等待太久（演示蓄力改为 1.6 / 0.9 / 0.9 s 三段，完美 1.4 s、超级 3.3 s、超载 3.4 s）；镜头震动太弱。

### 15 · 飞行表现
- 航线：爬升 → 进月球门 → 绕月 N 圈 →（可选转场木星）→ 返航 → 悬停 → 降落。
- 喷口外发光 + 点光源、尾焰色拖尾、白色航迹云；过门金色闪光环 + 火花。
- **轨道狂热**：彩虹冲击环与火花、彩虹尾焰 / 拖尾 / 星火；轨道虚线变流动彩虹、轨道门切 fever（放大 1.6 倍）；离开轨道恢复。
- 邻居的狂热只显示在他的火箭上（彩虹尾迹所有人可见），不改世界里的轨道线和门。
- 降落：反推尾焰，落地前缩回原尺寸。

### 16 · 完美接住 / 连续接住
- 降落时显示接住区光柱（白 → 黄 → 绿），离台 14 格内扬尘。
- 支架合拢角按火箭实际宽度自动计算（巨型燃料舱不再被夹穿）。
- **完美**：火箭放大 6% 回弹定格、夹口大火花、金白双层冲击波、70 片彩色纸屑、金光 + 震动；连击 ≥ 3 火花加倍；连击 ≥ 5 两只支架之间 1.6 s 青白电弧。
- **良好**：蓝色冲击波 + 少量火花。**太早**：支架空合弹回，火箭落台弹一下再夹紧。

### 17 · 华丽坠毁 + 维修无人机（约 5.3 s）
- 火箭倾倒 → 卡通爆炸（橙色火球、白热闪光、火花、黑 / 橙烟、冲击环、强震）→ 拆成发动机 / 燃料舱 / 鼻锥 / 四片尾翼四散弹跳冒烟。
- 维修无人机从组装舱上空飞来悬停，青色修复光锥照住发射台，部件依次沿弧线飞回、卡上冒火花，焊接臂迸焊花 → 青色爆闪「修好了」→ 无人机飞走，支架合拢。
- **无人机造型**：深蓝机身 + 白色顶壳 + 橙色饰条，四旋翼，机腹青色「眼睛」+ 焊接臂，约 6 × 1.6 × 6；按组装舱龙门吊的造型语言设计。**原画 E1 待补。**
- **验收台 `_DroneReview`**（付费支架验收台南边）：左边放大 2.5 倍自转，右边原尺寸悬停在一档火箭上方并打开修复光锥。验收后整块删除。

### 18 · 木星解锁演出（约 4.6 s）
- 护盾闪烁加速 → 朝镜头一侧爬出白色裂纹 + 淡紫闪屏 → 护盾抖动 → 碎成约 300 颗紫 / 金 / 白 / 橙光点 + 金紫冲击环 + 暖白闪屏 + 震动 → 木星恢复全彩（饱和 ×1.35、亮度 ×1.4），三层行星环从 0.5 倍展开到原大。
- 同时：锁定牌隐藏、轨道门 locked → normal、轨道虚线变白。
- 演出时镜头自动对准木星，结束还给玩家。
- 接口：`J.play({camera = true})`、`J.setUnlocked(0/1)`（读档用）、`J.reset()`。
- 锁定原色存在零件属性里，反复测试不会漂色；木星模型改为常驻加载，避免轨道门没加载时演出中断。

### 19 · 围观访客 ×3
- 每家 3 人（6 家共 18 人），站在发射台周围面朝台：
  - **Leo**：黄帽、蓝衣、黑裤
  - **Mia**：粉帽、绿衣、蓝裤
  - **Sam**：白帽、紫衣、藏青裤
- 标准 R15 体型（与玩家同大），头顶显示名字（60 格内）。
- **动作**：待机轻摆臂；欢呼时双手举过头挥、原地蹦、抬头看天；被掀翻时空中翻滚、四肢乱甩 → 落地弹一下 + 扬尘 → 仰面躺 1.4 s → 爬起 → 走回原位 → 接着欢呼。撞墙或到岛边会弹回，不会飞出岛。
- **触发**：超级发射掀翻 + 欢呼 3 s；完美发射 2 s；普通 1.5 s；熄火 1 s；完美接住 2 s（连击 ≥ 3 为 3 s）；良好接住 1.5 s；坠毁爆炸掀翻 + 欢呼 2.5 s。
- 实测超级发射：Leo 飞出 28 格、Mia 20 格、Sam 18 格，约 7 s 后全部回位。
- **与计划的差异**：计划写「布娃娃用引擎物理」，实际用程序化翻滚（和 Web Demo 一致），玩家端完全可控、不卡地形；需要真物理再议。
- 仅 Studio：`workspace._VisitorDebug` 可在命令栏触发欢呼 / 掀翻，正式发布的游戏里不生成。

### 20 · 广场内容
- **火箭雕塑**：中央圆台上石墨色底座 + 金色饰环，火箭为气动鼻锥 + 巨型燃料舱 + 等离子发动机 + 基础尾翼（Web Demo 同款），放大 1.6 倍，金色，缓慢自转；四周 6 盏青色地灯朝上照。
- **公共商店位 ×3**：30° / 150° / 270°（两座桥之间），正面朝广场中心；白色小屋 + 卷帘门 + 条纹遮阳棚 + 柜台 +「即将开放 · 公共商店」招牌，点缀色分别为金 / 青 / 粉。商店内容待商业化设计。

### 21 · 全局氛围 · 流星
- 远空每 2–6.5 s 划过一颗：发光头 + 约 180 格拖尾，1.2 s 划过，先亮后暗；数值沿用 Web Demo × 1.3。只在客户端生成，不进物理。
- 「从邻居家能读懂星球特征」：月球、木星（锁定紫盾 / 解锁全彩 + 行星环）P0 起已可从各家看到，本项未另改。
